# Data sources (v0 sourcing run, 2026-11-10)

All Freesound audio below is the site's **preview** (HQ mp3, ~128 kbps) fetched without an API key or login; originals need a login. Previews are lossy, which is fine for ASR but note it. No audio was listened to by the agent: "human/automated", accent and noise columns come from titles/descriptions only and are **unverified** unless stated. Nothing was transcribed or labelled. ## C. Existing datasets of transit announcements with transcripts

- **RailKosh / RailVaani** (EMNLP 2026 demos, https://aclanthology.org/2026.emnlp-demos.51/): 1,513 real railway PA clips (1,000 English, 513 Hindi), 53 Indian stations, gold transcripts + entity labels. Paper says "fully open-source" but gives no download link or dataset licence on the page; Indian English accent, station PA (not UK, not onboard). Worth emailing authors / checking the PDF for a repo. Not downloaded.
- Closest analogue domain: ATC speech corpora with transcripts (ATCO2, ATCOSIM, UWB-ATCC, HF `jacktol/ATC-ASR-Dataset`): noisy, entity-heavy, domain-specific, but not transit.
- Hungarian railway TTS corpus (Interspeech 2015) and a 230-utterance Indian "announcement for deaf" system: no usable public ASR data found.
- No UK rail/tube announcement dataset with transcripts found.

## Gaps / recommendations

- Human **onboard, phone-recorded, noisy** UK clips are thin on Freesound: most are hobbyist station recordings with good mics, and ~half of the human/automated labels are unverified. Funny/viral phone clips only exist as YouTube links (4 + forum indexes); the user must decide on ToS; tools like yt-dlp are not installed/used here.
- Many clips are pre-2012 and some are 1-2 minutes with several announcements: need trimming to one announcement each. Previews are lossy mp3.
- Recommended next step: listen to the 24 clips, drop automated ones, then add 10-15 from YouTube (via the Rail Forums threads) and consider TikTok/Reddit search by hand (my Reddit search returned nothing).
- Noise: licence of DEMAND (CC-BY vs CC-BY-SA) should be checked; no noise file was checked for absence of speech; moving UK mainline interior noise is only one clip (533718). Freesound licence strings were scraped from page links and the BBC licence only from secondary sources.
- Licence concerns: fs40156, fs96502, fs95874, fs62314 are CC-BY-NC (fine for research, not for a commercial demo). Don't commit audio; CC-BY items need attribution if redistributed.
